# Exploratory Data Analysis (EDA) on Retail Sales Data

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on retail sales data to understand sales patterns, customer behavior, and business insights.

## Dataset
Retail Sales dataset is used for analyzing sales-related information.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed
- Data loading
- Data cleaning
- Checking missing values
- Exploratory Data Analysis
- Data visualization
- Finding sales trends and insights

## Conclusion
The analysis helps to understand customer purchasing patterns and identify important trends in retail sales data.
